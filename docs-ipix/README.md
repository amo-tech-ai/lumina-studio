# iPix Documentation

This directory is the curated source for the iPix Mintlify documentation portal.

## Structure

- `getting-started/` — onboarding, local development, environment, deployment
- `product/` — product areas, PRDs, user journeys
- `ai/` — agents, Mastra, CopilotKit, HITL, models, AI Gateway
- `platform/` — Supabase, Cloudflare, Cloudinary, security
- `engineering/` — development workflow, design system, testing, skills
- `api/` — APIs, schema, RPCs, edge functions, webhooks
- `integrations/` — external platform integrations
- `operations/` — deployment, monitoring, troubleshooting, runbooks
- `plans/` — active plans and roadmap material
- `archive/` — superseded or historical documentation

## Rule

Keep this directory curated. Do not bulk-copy temporary notes, PR-specific files, audits, secrets, credentials, or obsolete plans into the published documentation.
